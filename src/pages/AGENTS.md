# ChatRoom 聊天室

基于 Socket.IO 的实时聊天室应用。

## 技术栈

- **前端**: React 19 + TypeScript + Socket.IO Client
- **后端**: Express + Socket.IO
- **样式**: Tailwind CSS

## 已实现功能

### 1. 用户登录
- 输入昵称后回车登录
- 服务端校验用户名唯一性
- 登录成功后进入聊天室

### 2. 消息收发
- 输入框支持回车发送、Shift+Enter 换行
- 消息气泡区分自己和他人（绿色/灰色）
- 支持图片粘贴发送（粘贴即时转 base64 通过 socket 发送）
- 消息类型：`text` / `image`（MsgList 接口含 `type` 字段）

### 3. 在线用户列表
- 侧边栏 240px 固定宽度
- 显示当前在线用户数量
- 用户登录/登出时实时更新
- 绿色呼吸灯动画指示在线状态

### 4. 智能自动滚动
- 使用 `useRef` 追踪用户是否在底部区域（通过 `scroll` 事件持续更新）
- 新消息到达时，仅在用户处于底部时自动 `scrollIntoView`
- 用户查看历史记录时不打断操作

### 5. 回到底部按钮
- 用户滚动到底部 50px 范围外时显示浮动按钮
- 点击按钮平滑滚动到底部

### 6. 消息展示
- 默认灰色圆形 SVG 头像（圆形底 + 剪影）
- 头像与消息气泡横向排列（自己靠右，他人靠左）
- 自己消息绿色气泡，他人灰色气泡

### 7. 滚动条优化
- 滚动条默认透明隐藏
- 鼠标 hover 滚动区域时显示半透明灰色细滚动条
- 兼容 Webkit（Chrome/Edge）和 Firefox

## Socket 事件

| 事件 | 方向 | 说明 |
|------|------|------|
| `user-login` | 客户端 → 服务端 | 登录请求，携带 ack 回调 |
| `send-msg` | 客户端 → 服务端 | 发送消息，携带 ack 回调 |
| `chat-msg` | 服务端 → 客户端 | 广播消息到所有客户端 |
| `online-user` | 服务端 → 客户端 | 广播在线用户列表 |
